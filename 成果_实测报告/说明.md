## 观测

- 点位：校园商业街角（便利店门前广场 + 校园出入口 + 自行车/电动车停放带）
- 素材：既有固定机位拍摄，非摆拍；四层楼下俯视，广角
- 机位稳定性：30 分钟内首尾帧配准位移 0.1 像素，旋转 0.0°
- 分析窗口：原片第 4:00–14:00，10 分钟 / 18 000 帧 / 30 fps
- 处理：4K 缩放至 1080p 后逐帧分析；**没有重新训练任何模型**

## 口径与边界（引用时请一并说明）

1. **没有地面标定**：所有距离、面积以“画面宽比例”表达，不出米制密度。补一次矩形量测即可全部升级为米制。
2. **轨迹条数 ≠ 人数**：跟踪 ID 会断裂，1 161 条行人轨迹不等于 1 161 个人，只能做相对比较。
3. **停留 ≠ 意愿**：只统计“会话内连续可见时长”，不能推断愿意待多久。
4. **交织 ≠ 险情**：是按地面距离筛出的“人车同时进入同一小块地面”的组数，用于定位复核点，不作安全评价。
5. **年龄与性别**：俯视机位下可见人脸比例低，样本偏差大，未纳入任何结论。

## 复现

界面：打开 `云瞰街巷.exe` → 载入示例片段 → 开始分析 → 自动生成空间画像。

命令行：

```powershell
python tools/space_pipeline.py <会话目录> --video <原视频> --playback 60
python tools/make_space_report.py --space <会话目录>/space --out 报告.docx
```
